# Ring Runner preview

`preview.jpg` is an unedited Playwright screenshot of ASTRA's local Ring Runner at 1280×800, captured November 13, 2026 with the explicitly illustrative daylight setting and course seed 73. It is used by the shared All activities card. The game scene is procedural canvas art based on the producer's supplied Ring Surfer prototype and ASTRA's milestone 1 ring study; no external runtime image is needed by the game.
