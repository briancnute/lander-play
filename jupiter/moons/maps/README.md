# Galilean globe maps

Retrieved November 4, 2026 from [NASA/JPL's Solar System Simulator texture catalogue](https://space.jpl.nasa.gov/tmaps/jupiter.html). These are original JPEG downloads, sampled onto ASTRA's existing globe renderer without raster edits. Source URLs, byte sizes, and SHA-256 hashes are in [provenance.json](provenance.json).

| File | Source credit and content |
| --- | --- |
| `io.jpg` | JPL/Caltech; David Seal. Voyager/USGS mosaic with Galileo global-mosaic color. |
| `europa.jpg` | Caltech/JPL/USGS. Cleaned Voyager grayscale mosaic. |
| `ganymede.jpg` | Caltech/JPL/USGS. Cleaned Voyager grayscale mosaic. |
| `callisto.jpg` | Caltech/JPL/USGS. Cleaned Voyager grayscale mosaic. |

All four maps are 1440 × 720 pixels. Coverage and resolution vary across the original spacecraft mosaics. Europa, Ganymede, and Callisto are intentionally grayscale source products, not claims of naked-eye color. The existing color disk photographs remain the small selector thumbnails.

The shared renderer adds sunlight and modest ambient illumination. Surface orientation uses an approximate synchronous frame whose prime direction faces Jupiter; the map registration does not provide survey-grade geographic longitude. No named surface target or mission is positioned from this map. Dated orbital positions are calculated independently of texture orientation.
